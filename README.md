# Compat Archaeologist

Before you migrate a database, get the archaeology done.

Compat Archaeologist reconstructs how an application really uses MongoDB from three kinds of evidence (data samples, query logs, application code). It then proves behavioral equivalence, or finds the gaps, by replaying probes on MongoDB and on a MongoDB-compatible target side by side.

Work in progress for the AIE Code Summit hackathon, 2026-11-07.
